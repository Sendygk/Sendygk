# Installation

1. Copy `README.md`, `assets`, and `.github` into the root of the `Sendygk/Sendygk` repository.
2. Commit and push all files to the `main` branch.
3. Open the repository's **Actions** tab and enable workflows if GitHub asks for confirmation.
4. Select **Generate contribution games**, choose **Run workflow**, and wait until it finishes.
5. Refresh the GitHub profile. The pink Snake animation will appear directly in **The Serpent's Path** section.

If the workflow cannot publish the `output` branch, open **Settings → Actions → General → Workflow permissions**, select **Read and write permissions**, and save. Then run the workflow again.
